# ИЛ-2: Небесный удар

Псевдо-3D авиационная аркада в духе классических 8-bit шутеров. Советский штурмовик **Ил-2** против авиации, флота и наземных сил.

## Запуск

> **Важно:** не открывайте `index.html` двойным щелчком — браузер заблокирует ES modules (`file://`).

**Windows:** дважды щёлкните `start.bat`

**Или в терминале:**

```bash
npm start
```

Затем откройте в браузере: **http://localhost:3000**

## Управление

### Desktop
- **Стрелки / WASD** — курс
- **Space / Z** — пушки (GUN)
- **X / Ctrl** — реактивные снаряды (ROCKET)
- **P / Escape** — пауза

### Mobile
- D-pad слева
- **GUN** и **ROCKET** справа

## Тесты

```bash
npm test
```

## Технологии

HTML5, CSS3, vanilla JavaScript (ES modules), Canvas 256×240, Web Audio API.
